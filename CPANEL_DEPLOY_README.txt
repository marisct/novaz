NovaX IMS cPanel hosting notes
==============================

Website URL:
https://novax.co4.in/

Database name:
cpfr_42287767_novax

Upload
------
1. Upload the ZIP file to your hosting file manager.
2. Extract it outside public_html if your cPanel supports a Laravel app folder.
3. Point the domain/subdomain document root to:
   public

If your hosting does not allow changing document root:
1. Extract the project into a folder such as nonax_app.
2. Copy everything inside nonax_app/public into public_html.
3. Edit public_html/index.php paths so they point to ../nonax_app/vendor/autoload.php and ../nonax_app/bootstrap/app.php.

Environment
-----------
1. The ZIP includes a cPanel-ready .env file.
2. Update these values from your hosting panel:
   DB_HOST
   DB_USERNAME
   DB_PASSWORD

Important:
The database name is already set to cpfr_42287767_novax.

Database import
---------------
The ZIP includes:
nonax-cpanel-database.sql

Open cPanel phpMyAdmin, select database cpfr_42287767_novax, then import this SQL file.
Do this only once on an empty database.

Install dependencies
--------------------
This source ZIP does not include the vendor folder so it stays small enough for free cPanel upload.
Run this command from cPanel Terminal inside the extracted project folder:

composer install --no-dev --optimize-autoloader

Commands to run from cPanel Terminal, if available
--------------------------------------------------
php artisan key:generate --force
php artisan storage:link
php artisan optimize:clear
php artisan config:cache
php artisan route:cache
php artisan view:cache

If you did not import nonax-cpanel-database.sql, run this instead before the cache commands:
php artisan migrate --seed --force

If you do not have cPanel Terminal
----------------------------------
Use phpMyAdmin to import nonax-cpanel-database.sql. The app still needs the Laravel
vendor folder, so ask the host if Composer/Terminal is available or upload a vendor
folder generated by running composer install locally.
